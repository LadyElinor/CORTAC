# Frozen protocol: CORTAC mechanism sandbox 1

Status: SCRIPTED MECHANISM SIMULATION. This is not a model-backed comparative study, independent-agent trial, or evidence of collective intelligence. No source repository files are changed. Source baseline is the supplied verified CORTAC 0.2.1 snapshot. This new reference transition system is not the unimplemented CORTAC runtime.

## Scope and causal interpretation
The five functions are evidence assessment, normative assessment, collective decision, execution authorization, and audit/correction. Proposal is an input. The full arm uses four decision seats (three approvals required) and three appeal seats (two approvals required). All names/control declarations are synthetic. The same-functions centralized control is byte-identical policy and cost to full, differing only in a topology label: equality is expected and proves this simulation does not identify benefits of organizational separation. Minimal uses one decision checker and same evidence competence, permission check, self-audit and repair. No conclusions about independent minds, real control, or deployment safety are possible.

## Frozen factorial design
7 families: benign, shared_false, conflicted_review, reviewer_shortage, review_withdrawal, target_drift, owner_revoked.
50 paired seeds (0..49), budgets 12 and 30 abstract work units, injected fault probabilities 0 and 0.20, fault correlation 0 and 1. Total 2,800 matched environments, 8 arms, 22,400 episodes. Include all cells, with no selected winner or inferential significance claim. p=0 duplicate correlation settings remain explicit controls.
Arms: minimal; full; centralized_full; full_no_control_exclusion; full_no_continuity; full_no_classification; full_no_audit; full_single_decider. Ablations alter only the named flag or seat threshold. No model tokens or monetary costs are consumed/measured.

## Environment, faults, information
All arms receive the same proposal, two agreeing independent observations in normal cases, source provenance, current owner permission, reviewer availability/control declarations and complaint. Ground truth is an integer derived from seed. Shared_false instead presents two copies of one false observation and one independent true observation; the common evidence algorithm requires at least two distinct agreeing origins and no contradictory values, so correctly defers this unresolved case. No extra observation is supplied to full. Target drift changes the target from a to b, both owner-authorized; b requires internal reclassification, so an internal classification violation is not an owner-permission violation. Owner_revoked forbids any edit at the common gateway.
Ordinary tasks start pending. Four recovery families (conflicted_review, reviewer_shortage, review_withdrawal, target_drift) instead start with one prior wrong index value and a complaint, providing an arm-independent recovery denominator. All recovery families have valid current source evidence; shortage has two available appeal seats, withdrawal has the ordinary review allocation withdrawn but a protected review allocation of the same size available to every arm that retains it. Minimal retains protected continuity but may use one unconflicted reviewer; full requires three. Conflicted review has four nominal candidates, first under prior decision control, three clean replacements. Conflict-ablated full picks first three. Normative integrity is common-owner permission, not full-arm internal rules.
Each checker uses the same evidence algorithm. A synthetic cognitive fault flips the affected checker's approval bit; a seat0 evidence fault increments the proposed observed value by one (see exact semantics below). This models a malfunction, not LLM judgment. All randomness is SHA-256-derived by (seed, family, purpose, seat); arm names are absent. At correlation=1 every checker and auditor shares one fault bit; correlation=0 uses separate seat labels. Full's epistemic vote is seat 0; minimal's decision uses seat 0; full uses seats 0..3. Audit has its own label under independent faults. No values/probabilities are tuned after runs. Fully common-mode faults explicitly test whether quorum fails together.

## Transition/cost schedule
Every episode pays 1 intake, 1 evidence, 1 norms. Permission denial terminates safely after norms. Full/centralized/ablations pay 1 routing + 4 council checks; minimal pays 1 decision check. Single-decider ablation pays one council check. Approval requires 3/4 or 1/1. Rejection yields explicit abstention (even if caused by fault); no truth score is credited for safe inaction. Recovery-case review pays 1 roster check + one unit per required seat; conflict checking adds no capacity. Missing seats preserve complaint and terminate review_unavailable. Full without control exclusion records its use of a conflicted seat. Full/centralized continuity and minimal retain protected review allocation; continuity-ablated full terminates review_unavailable on withdrawal. Classification recheck costs 1 and updates the envelope to b when needed; classification ablation skips this check and records a violation if it requests execution for b. Every attempted edit pays 1 gateway + 1 commit; gateway enforces owner permission, scope and live budget. Every auditable edit pays 1 audit; an independent audit that detects wrong value may pay 1 repair gateway + 1 repair commit if budget remains. All spending is atomic per step and total includes routing, quorum, checks, audit and repair. Insufficient budget records timeout, never silently increases budget. Complaint remains recorded on all exits.

## Frozen metrics and reporting
Raw action trace, terminal status, final state, units spent, first correct effect tick plus episode end tick (serial unit counts), wrong final state, any wrong effect, unauthorized attempts and effects, classification violations, conflicted review, recovery success, abstention, timeout, unavailable review, and complaint preservation. Completion means correct final state and permitted requested task delivered by budget; abstention does not count. Shared_false has no justified edit, so report this family's no-edit integrity separately and do not reward it as completion. Recovery denominator is all four recovery families, regardless of arm initial outcome. Measure Python process CPU/wall runtime for the whole runner separately; never call it agent latency. Paired differences are descriptive finite-case means, without p-values or confidence intervals: seeds generate synthetic numeric values and faults, not a sampled population of real tasks. Publish per-family, per-budget, per-fault/correlation, aggregate and paired full-minus-minimal results. Aggregate mixture is arbitrary, not headline utility. Report unit counts rather than invented token equivalents.

## Integrity gates and stopping
Before main scoring freeze protocol, runner, and tests SHA-256 with UTC timestamp; send design for review. Run planted unit controls and upstream verification. Judge derives truth from environment and inspects state/effects rather than trusting actor claims. Require exact centralized/full equality, no budget exceedance, owner-unauthorized effects zero, baseline error-free benign completion at generous budget and no arm edits unresolved evidence at zero faults. Replay raw deterministic output exactly. No further policy tuning after main run; defects invalidate affected results and require a separately labeled protocol revision. Stop after one frozen run, validation, independent review and reproducible delivery. ## Pre-freeze clarifications and source correspondence
The source is the pinned CORTAC WAC 0.2.1 consequential-case profile, not the earlier Assembly Specification v0.1 record-ordering validator proposal. Four council seats/three approvals are decision policy, explicitly not Byzantine consensus. These experiments concern consequential shared commitments; routine standing-warrant lanes need not pay this overhead.
The full appeal panel must have three valid members but passes on two approvals. Its shortage result follows the staffing requirement, not unanimity. The common minimal baseline may use one qualified unconflicted reviewer.
Exact fault semantics: evidence checker seat0 proposes the sole agreed observed value when sources suffice, otherwise the first source value; a seat0 fault increments that candidate by one. Each decision seat independently computes (sources sufficient AND candidate equals agreed observed value), then XORs that bit with its fault. Appeal checks do the same using separate review labels. The auditor computes (sources sufficient AND state differs from agreed value), then XORs its fault; any repair uses the agreed observation. No actor receives evaluator truth. Under common-mode faults all these fault bits coincide. Source observations in the shared-false family remain unresolved even though the evaluator knows hidden truth.
Every family with a complaint has a separate, explicit, still-live owner remedy grant allowing one correction of the specified index value, plus at most one corrective retry, under the same total ceiling. Review-withdrawal withdraws only ordinary operator-controlled review funding. Protected review funding permits adjudication only, never execution. The independent remedy grant permits the correction; it is the same in every arm and never manufactured by the review outcome. The owner_revoked family has no current execution grant. There are no external actions.
Mapping: four/three consequential council and protected-failure semantics are inspired by profile.consequential_decision; synthetic appeal exclusions and three/two decisions by profile.independence_requirements.appeal and appeal; classification and gateway by source arm_definitions.authorization_checked_classification; continuity by source arm_definitions.independent_review_continuity_grant. All declared control is unverified. Minimal also retains control checks, classification, protected review and audit, so centralization is not penalized by deleting these safeguards.
Omitted: the proposed ordinary role-separated arm, inherited cell weights and federation, actual identity authentication and control discovery, signed capabilities, concurrency/races, persistent logs, lottery, source discovery, model-generated reasons, social fairness, adversarial strategic behavior, long-horizon tasks and provider costs. A full council in this abstraction checks semantic proposal validity; this does not claim that repeated deterministic checks supply factual independence. Full-agent independence/authorizer process isolation/audit independence and legitimate charter adoption are not implemented.
The planned source study's model-backed analysis and bootstrap remain blocked. This finite scripted census uses descriptive paired contrasts only; fifty seeds vary faults/numbers within seven hand-designed templates, not fifty independently sampled real task families. Model and inference endpoint availability checks found no callable metered inference tool or local model runner/weights in the accessible task workspace. Native conversational agents are available but lack the fixed per-episode token/API accounting needed here. No provider credentials were read or configured.
